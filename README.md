# ✨ AI Prompt Enhancer

AI Prompt Enhancer is a Generative AI application that transforms simple image descriptions into detailed, professional-quality prompts for AI image generation models.

The system uses a local Large Language Model (Gemma 3 via Ollama) to generate multiple enhanced prompt variations along with explanations of why each prompt is effective.

---

## 🚀 Features

- Convert simple ideas into professional prompts
- Generate 3 prompt variations
- Style-based prompt generation
- Individual copy button for each prompt
- Prompt reasoning and explanation
- Prompt history
- Character counter
- Interactive style selection
- Responsive modern UI
- Fully local AI inference using Ollama
